## 说明

本清单用于明确小程序一期的开发范围，将功能划分为 **本期纳入**、**本期不纳入**、**待确认** 三类。范围确认后，将作为后续开发与验收的依据。报价与工期另行单独沟通。

---

## ✅ 本期纳入（共 11 个模块）

| 序号 | 模块 | 功能说明 |
| :---: | --- | --- |
| 1 | 赛事信息发布与管理 | 赛事新增/编辑/上下架；赛事详情（规程、时间、地点、组别、主办承办）；**赛事三级分类（分站赛 / 市级赛 / 年度赛）** |
| 2 | 在线报名 | 个人报名、团队报名（队长建队、邀请队员）；报名信息字段可配置（必填/选填/自定义新增）；资格审核（通过/驳回）、人数限制、报名截止时间 |
| 3 | 赛程对阵 | 赛程安排（分组、场次、对阵表）；后台**手动排对阵 / 自动生成对阵** |
| 4 | 成绩与排名 | 成绩录入（手工 + Excel 批量导入）；自动排名（成绩优者靠前、单项同分并列、多项积分累加） |
| 5 | 赛事日历 | 赛事排期展示、按日期查看赛事安排 |
| 6 | 资讯发布 | 新闻、赛事通知、竞赛规程、获奖公示 |
| 7 | 参赛积分 | 积分总览、明细、会员等级（注册/铜/银/金/铂金）；积分按报名、完赛、名次自动累计 |
| 8 | 短视频 | 赛事动态、精彩回顾，采用**视频号内嵌播放**（运营发布视频号，小程序内直接播放） |
| 9 | 消息通知 | 微信订阅消息：报名成功提醒、开赛提醒（用户主动订阅后推送） |
| 10 | 主题 / 背景设置 | 后台动态设置小程序背景（颜色 / 图片），无需重新发版、无需等待审核 |
| 11 | 多管理员 | 后台支持多个管理员账号登录，当前为**统一权限**（所有管理员权限一致） |
