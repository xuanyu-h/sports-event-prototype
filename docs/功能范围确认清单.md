## 说明

本清单将小程序功能按 **三档方案**（标准版 / 进阶版 / 尊享版）划分。其中「所有方案均含」为基础核心模块，「按档位增配」为增值模块。范围确认后，将作为后续开发与验收的依据。

> **需求沟通与修改边界：** 报价含 2 轮整体方案确认 + 各模块常规细节微调；方案定稿签字后，推翻重做或新增模块视为新需求，另行报价。

---

## ✅ 所有方案均含（7 个核心模块）

| 序号 | 模块 | 功能说明 |
| :---: | --- | --- |
| 1 | 赛事信息发布与管理 | 赛事新增/编辑/上下架；赛事详情（规程、时间、地点、组别、主办承办）；赛事三级分类（分站赛 / 市级赛 / 年度赛） |
| 2 | 在线报名 | 个人报名、团队报名（队长建队、邀请队员）；报名信息字段可配置；资格审核；人数限制、报名截止时间 |
| 3 | 赛程对阵 | 赛程安排（分组、场次、对阵表）；后台手动排对阵 / 自动生成对阵 |
| 4 | 成绩与排名 | 成绩录入（手工 + Excel 批量导入）；自动排名（成绩优者靠前、单项同分并列、多项积分累加） |
| 5 | 赛事日历 | 赛事排期展示、按日期查看赛事安排 |
| 6 | 资讯发布 | 新闻、通知、规程、获奖公示等内容的发布与管理 |
| 7 | 消息通知 | 微信订阅消息：报名成功提醒、开赛提醒等 |
