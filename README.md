# 体竞文化 · 体育赛事服务小程序 · 页面原型

面向体育赛事场景的小程序，包含**参赛用户端**（微信小程序）与 **PC 管理后台**。

> 本仓库仅托管**页面原型**，供客户预览与需求沟通使用。
> 开发文档（需求规格 / 数据库 / 接口 / 技术选型）见私有仓库 `tjsports-event-platform`。

## 在线预览

https://xuanyu-h.github.io/sports-event-prototype/

> 建议在**手机微信**中打开预览链接，模拟真实小程序使用体验。

## 原型页面索引

### 参赛用户端（C 端 · 微信小程序）

| 页面 | 说明 |
| --- | --- |
| 首页 | 搜索 + 热门赛事轮播 + 快捷入口 + 6 种背景主题切换 |
| 赛事列表 / 详情 | 三级分类、报名按钮、签到入口 |
| 报名流程 | 个人 / 团队模式、字段动态配置、邀请码 |
| 赛程对阵 | 半决赛 / 决赛对阵表、实时比分 |
| 成绩排名 | 自动排名、同分并列处理 |
| 赛事日历 | 排期展示、按日期查看 |
| 资讯中心 | 三类资讯（通知 / 预告 / 图文） |
| 现场签到 | 扫码签到、签到记录 |
| 我的 | 个人资料、报名 / 签到 / 成绩、参赛积分（5 级会员） |

## 原型操作提示

- **顶部 Tab** 可切换 **C 端（小程序）** 与 **PC 管理后台** 视角
- **C 端首页** 支持 6 种背景主题切换（浅灰 / 清爽蓝 / 暖阳 / 活力绿 / 薄荷 / 进阶版）
- 主题/SEO 设置项标有「**进阶版**」徽标的为版本差异功能
- 所有页面均可点击交互，模拟真实流程
