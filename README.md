# 体竞文化 · 体育赛事服务小程序

面向体育赛事场景的小程序，包含**参赛用户端**与 **PC 管理后台**。原型为单文件交互式 HTML，可在线预览。

## 在线预览

| 版本 | 链接 | 说明 |
| --- | --- | --- |
| **v2.0 完整版** | https://xuanyu-h.github.io/sports-event-prototype/ | 11 个模块（当前主版本） |
| **v1.0 基础版** | https://xuanyu-h.github.io/sports-event-prototype/v1/ | 4 个模块（基线存档） |

> 两个版本页面右下角均有「版本切换」浮标，可互相跳转。

## v2.0 完整版 · 一期范围（11 个模块）

| # | 模块 | 说明 |
| --- | --- | --- |
| 1 | 赛事信息发布与管理 | 赛事增删改、详情、三级分类（分站赛 / 市级赛 / 年度赛） |
| 2 | 在线报名 | 个人 + 团队报名、字段可配置、资格审核 |
| 3 | 赛程对阵 | 分组、场次、对阵表（手动排阵 / 自动生成） |
| 4 | 成绩与排名 | 成绩录入、Excel 导入、自动排名 |
| 5 | 赛事日历 | 排期展示、按日期查看 |
| 6 | 资讯发布 | 新闻、通知、规程、公示 |
| 7 | 参赛积分 | 积分明细、会员等级、自动累计 |
| 8 | 短视频 | 视频号内嵌播放 |
| 9 | 消息通知 | 微信订阅消息推送 |
| 10 | 主题 / 背景设置 | 后台动态换背景，无需发版 |
| 11 | 多管理员 | 多个管理员账号（统一权限） |

### 本期不纳入

抽奖、积分商城、票务 / 购票领票、用户管理扩展。

## 原型操作提示

- 顶部可切换 **C 端（小程序）** 与 **PC 管理后台** 视角
- 首页支持背景主题切换（浅灰 / 清爽蓝 / 暖阳 / 活力绿 / 薄荷）
