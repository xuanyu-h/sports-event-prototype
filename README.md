# 体竞文化 · 体育赛事服务小程序

面向体育赛事场景的小程序，包含**参赛用户端**与 **PC 管理后台**。原型为单文件交互式 HTML，可在线预览。

## 在线预览

https://xuanyu-h.github.io/sports-event-prototype/

## 功能范围（11 个模块）

| # | 模块 | 说明 |
| --- | --- | --- |
| 1 | 赛事信息发布与管理 | 赛事增删改、详情、三级分类（分站赛 / 市级赛 / 年度赛） |
| 2 | 在线报名 | 个人 + 团队报名、字段可配置、资格审核 |
| 3 | 赛程对阵 | 分组、场次、对阵表（手动排阵 / 自动生成） |
| 4 | 成绩与排名 | 成绩录入、Excel 导入、自动排名 |
| 5 | 赛事日历 | 排期展示、按日期查看 |
| 6 | 资讯发布 | 新闻、通知、规程、公示 |
| 7 | 消息通知 | 微信订阅消息推送 |
| 8 | 主题 / 背景设置 | 后台动态换背景，无需发版 |
| 9 | 参赛积分 | 积分明细、会员等级、自动累计 |
| 10 | 精彩瞬间 | 视频号内嵌播放 |
| 11 | 多管理员 | 多个管理员账号 |

### 本期不纳入
